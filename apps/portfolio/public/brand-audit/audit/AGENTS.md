# Brand Audit Evidence Agent Contract

## Operational Flow

Regenerate evidence through the portfolio audit commands, review the resulting
boards and metrics, and update this README when the accepted result changes.

## Required Verification Parameters Within Nested Context

Run `portfolio:typecheck`, `portfolio:test`, `portfolio:publish`, and the
relevant `portfolio:audit` workflow before accepting refreshed evidence.

## Required Invariants Within Folder Context

Do not hand-edit generated evidence to improve a result. Evidence must remain
traceable to checked-in brand source, scripts, and reference inputs.
