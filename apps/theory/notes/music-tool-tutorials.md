# theory — music tool tutorials and how-to videos

Learning references for all **32 distinct tools** in the
[similar-apps comparison](similar-apps-and-services.md) and
[non-AI systems survey](non-ai-generative-music-systems-and-market-survey.md).
Repeated products are listed once. Incidental mentions of host DAWs and
dependencies are outside this index.

Links favor official tutorials, manuals, and project-maintained learning hubs.
Community videos are labeled when curated by a project or hosted in its forum.
Pages and tutorial listings were checked during this collection; videos were
not watched end to end and apps were not installed. A manual or demo is labeled
as such, rather than presented as a video course. Access limitations appear in
the relevant row.

## Generative sequencers and pattern tools

| App | Tutorials and how-to references | Format and useful starting point |
| --- | --- | --- |
| **Wotja** | [Tutorials](https://wotja.com/tutorials/) | **Official videos and written guides.** Start with the guided tour, then creating mixes, editing generators and rules, recording, or MIDI. Includes both short task guides and deeper videos. |
| **Nodal** | [Tutorials and examples](https://nodalmusic.com/tutorials/) | **Official introductory videos plus contributed examples.** Introduction, node types, and synchronization with Ableton Live; useful for seeing graph traversal become music. |
| **Strudel** | [Getting started](https://strudel.cc/workshop/getting-started/) | **Interactive written workshop with playable code.** Follow the workshop through sounds, notes, effects, and pattern effects. A hands-on tutorial rather than a video series. |
| **Stochas** | [Videos](https://stochas.org/vids/) · [Documentation](https://stochas.org/documentation/) | **Project-curated tutorials, demos, and reviews; written manual.** Start with basic features or the evolving drum-pattern tutorial. The site marks some videos as dated and says the original manual is being updated for the open-source version. |
| **Senode** | [Help manual](https://senode.org/help_1.4.2.html) · [Official site and videos](https://senode.org/) | **Written how-to, embedded videos, and in-app tutorial/example patches.** Learn nodes, edges, emitters, and playback. The site videos are presented as demonstrations, not a verified structured course; help is versioned 1.4.2. |
| **WolframTones** | [Composition controls](https://tones.wolfram.com/about/controls/) · [FAQ](https://tones.wolfram.com/about/faqs) | **Written controls reference and how-to FAQ.** Covers generator rules, instrumentation, pitch mapping, and time controls. Official indexed text was available, but direct page extraction was empty. No dedicated official tutorial-video series was established in this search. |
| **VCV Rack** | [Getting started](https://vcvrack.com/manual/GettingStarted) · [Video tutorial collection](https://community.vcvrack.com/t/getting-started-with-vcv-rack-video-tutorials/11204) | **Official written guide and community-curated videos on the VCV forum.** Start with audio setup and the template patch, then the Rack 2 beginner videos. The collection also contains older-version material. |
| **Common Music / Grace** | [Common Music 3 reference](https://commonmusic.sourceforge.net/cm/res/doc/cm.html) · [Legacy tutorials](https://commonmusic.sourceforge.net/cm2/etc/tutorials/index.html) | **Written reference with examples; legacy coding tutorials.** CM3 covers transformations, randomness, patterns, and output. The older tutorial set targets CM 2.7+ and dates to 2005; it is not a current Grace walkthrough. Its indexed contents were available, but a direct fetch timed out. |

## Visual music theory and songwriting

| App | Verified tutorial links | Format, coverage, and caveats |
| --- | --- | --- |
| Chromatone | [Theory learning hub](https://chromatone.center/theory/); [MIDI Roll instructions](https://chromatone.center/practice/midi/roll/) | Written lessons and tool-specific how-to instructions. Covers intervals, chords, scales, harmony, rhythm, and composition; MIDI Roll includes steps for keyboard/MIDI input, direction, speed, and filtering. A dedicated public video tutorial series was not verified in this pass. |
| TonnetzViz | [Official usage guide](https://github.com/cifkao/tonnetz-viz#usage); [Developer-linked video playlist](https://www.youtube.com/playlist?list=PLPdw6Kin7U86ccF4atsm7E9HkWPwFGKvj) | Short written setup guide for MIDI input, keyboard controls, and the built-in synth. The repository links the playlist as “Videos”; treat it as visualization examples, not a verified step-by-step course. YouTube exposed only limited playlist metadata. |
| Groove Pizza | [Co-creator's tutorials and resources](https://www.ethanhein.com/wp/cv/groove-pizza/); [NYU project and videos](https://www.musedlab.org/groovepizza/) | Embedded tutorial videos plus written beatmaking challenges and examples. Useful for circular drum sequencing, geometric rhythm patterns, classic beats, and trap beats. Ethan Hein is credited as a co-creator on the NYU page. |
| muted.io | [Super Simple Sequencer guide](https://muted.io/sequencer/); [Interactive theory references](https://muted.io/) | Written instructions alongside interactive tools. The sequencer page explains loop length, tempo, octave range, duplicate/mirror modes, and MIDI export. No dedicated official video tutorial library was verified in this pass. |
| Midinous | [Official manuals, by version](https://github.com/Nornec/Midinous-Issues); [Official video channel](https://www.youtube.com/channel/UCVUr0uNVwrfvl3IKF-f7bwQ); [Developer-confirmed guide discussion](https://steamcommunity.com/app/1727420/discussions/0/3837676281060536833/) | PDF manuals plus developer videos. The developer confirms an older “Features and Functions Stream” in the linked discussion; use the manual matching the installed version. The website and repository both link the video channel, but YouTube video listings could not be fully inspected. |
| Fugue Machine / Fugue Machine Classic | [Official videos](https://alexandernaut.com/fugue-machine-classic/videos/) | Demonstrations rather than a labeled beginner tutorial course: per-playhead MIDI routing, Ableton Link, AUv3 instances in AUM, and melody examples. Applies to Classic; do not substitute newer Fugue Machine Rubato instructions. |
| Hookpad | [Video tutorials](https://www.hooktheory.com/videos); [User guide](https://www.hooktheory.com/support/hookpad) | Dedicated beginner video series covering the interface, melody, and chords; further videos cover MIDI export and production workflows. Written guide covers composition, harmony controls, playback, and export. |
| Touch Tonnetz | [Official listing and in-app Help reference](https://apps.apple.com/us/app/touch-tonnetz/id1176422445) | The developer's release notes identify in-app Help with a short theory primer. No separate public tutorial page or official how-to video was verified after bounded searches; the store listing is a fallback reference, not a tutorial. |
| Mapping Tonal Harmony Pro | [Official demos, tutorials, and lessons](https://mdecks.com/mapharmony.phtml) | Video hub with a quick start and lessons for navigating the harmony map, analysis, reharmonization, and practice. The official page's embedded Quick Start was present; direct YouTube playback could not be fetched by the research tool. Older videos may show older app versions. |
| Tonaly | [Official user guide and video tutorials](https://guide.tonaly.app/) | Written guide plus five embedded video tutorials. The guide recommends starting with “How to compose” or “Learn and practice scales”; covers iOS, iPad, and macOS. |

| SuperCollider | [Getting Started with SC](https://doc.sccode.org/Tutorials/Getting-Started/00-Getting-Started-With-SC.html); [project tutorial directory](https://github.com/supercollider/supercollider/wiki/Tutorials); [Eli Fieldsteel video playlist](https://www.youtube.com/playlist?list=PLPYzvS8A_rTaNDweXe6PX4CXSGq4iEWYC) | Official written lessons cover synthesis, buffers, scheduling, routines, and patterns. | Sonic Pi | [Official tutorial](https://sonic-pi.net/tutorial.html); [Sam Aaron's video channel](https://youtube.com/samaaron) | Written progression through live loops, randomization, chords, scales, MIDI, OSC, and synthesis. Covers sound generation, timing, and concurrency. The short written tutorial is marked 1.2.x and command-line oriented; the learning hub is marked 1.5.x. Video destination was fetch-throttled, but the exact link and attribution were verified on the official directory. |
| ORCA | [Official README and operator guide](https://github.com/hundredrabbits/Orca/blob/main/README.md); [Learn ORCA Livecoding: In Depth Tutorial, part 1](https://www.youtube.com/watch?v=ktcWOLeWP-g) | Written operator/MIDI/OSC reference plus a video tutorial explicitly recommended in the project README. | Pure Data | [Official manual and guide to built-in tutorials](https://msp.ucsd.edu/Pd_documentation/1.introduction.htm); [Miller Puckette's Music 171 course](https://msp.ucsd.edu/syllabi/171.17w/); [course screen recordings](https://msp.ucsd.edu/syllabi/171.17w/movies/) | Official manual explains the interactive tutorial patches included with Pd. | Max | [Max tutorial series](https://docs.cycling74.com/learn/series/max-tutorials/); [Learn Max](https://cycling74.com/learn) | Official step-by-step written lessons and downloadable patchers, plus Cycling '74's own video links. The older website documentation route failed; use the linked project wiki. |
