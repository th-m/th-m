# Delegation Records

Copy the relevant structure into an owner-local Markdown plan or assignment.
Replace each field's guidance with the task's actual values. Omit optional
roles and measurements instead of inventing them.

## Shared Brief

| Field | Required content |
| --- | --- |
| Outcome | Deliverable, audience, and user constraints. |
| Owner | Nx project or documentation boundary and governing contracts. |
| Acceptance | Observable conditions for completion. |
| Inputs | Existing source, accepted evidence, and prerequisite artifacts. |
| Assignments | Worker role, objective, allowed files, expected outputs, and dependencies. |
| Integration | One writer responsible for shared destination files; coordinator responsible for final acceptance. |
| Verification | Actual owner targets and any manual review needed. |
| Stop conditions | Missing required evidence, scope conflicts, unavailable capability, or repeated identical failures. |
| Limits | Requested or supported attempt, time, token, and concurrency limits. |

## Worker Return

- **Result:** what was completed against the assigned objective.
- **Artifacts:** exact paths and whether they are proposals or integrated files.
- **Evidence:** sources and locators supporting material claims or decisions.
- **Checks:** commands actually run and their outcomes; distinguish manual review.
- **Open issues:** blockers, uncertainty, dependencies, and unfinished acceptance.
- **Handoff:** changes the integration writer must make or decisions the coordinator must resolve.

## Final Acceptance Report

- Identify the assembled deliverable and its owner.
- Map each acceptance condition to an artifact and evidence.
- Record resolved conflicts and any remaining limitation.
- Report verification performed on the integrated files, including failures.
- State whether the requested outcome is complete; preserve unfinished work
  and the exact blocker if it is not.

An assignment scopes work but does not configure permissions. Independent
research and disjoint files can run concurrently; shared edits require an
explicit integration sequence. The coordinator remains accountable even when
another worker performs integration.
