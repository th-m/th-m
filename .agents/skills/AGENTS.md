# Repository Skills Contract

## Operational Flow

Keep procedures here and production obligations in owner AGENTS files. Use
skill-creator guidance when available. Give each skill a narrow description,
actual inputs, useful steps, and a concrete result. Add resources only for a
repeated need. Maintain the local catalog and root routing together.

## Required Verification Parameters Within Nested Context

Validate required YAML frontmatter, name/folder agreement, local links, and
absence of placeholders. Walk through a realistic task and one that should
not select the skill. Run `testing:test` for documentation. Execute new
scripts against representative inputs.

## Required Invariants Within Folder Context

Skills preserve user scope and owner contracts. They cannot grant permissions,
claim unrun checks, or turn proposals into implemented features. Do not add
automatic commit, push, installation, scheduling, or external-message steps
as consequences of ordinary authoring or review.
