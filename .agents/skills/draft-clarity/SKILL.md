# Draft Clarity

Diagnose whether a cold reader can recover the intended point and its supporting
logic without borrowing the writer's background knowledge. Clarity means that
complexity is staged and connected, not removed or made generic.

## Set the Review Boundary

1. Identify the draft, intended reader, purpose, and whether the user wants an
   evaluation or an implemented revision.
2. Read the complete draft once in reading order before analyzing it. Record
   where the point becomes clear, where the logic requires an assumption, and
   where attention is likely to drop.
3. Read [the six-part system](references/six-part-system.md) before evaluating.
4. Default to the complete system for an article-length draft. For a section or
   targeted question, apply only the relevant passes plus dependencies needed
   to explain the result.

An evaluation is read-only. Change prose or files only when the user explicitly
asks for revision or implementation.

## Enforce the Cold-Reader Test

Judge each passage using only concepts, definitions, and evidence established
before or within that passage. Use briefs, notes, and repository context to
understand intended meaning, but never count them as clarity the draft has
earned on the page.

For each problem, identify:

- the exact passage or boundary;
- the assumption a reader must supply;
- the resulting reader cost, such as ambiguity, contradiction, lost sequence,
  or unsupported certainty;
- the smallest structural or verbal move that would restore the link.

Keep factual accuracy separate from textual clarity. A claim can be clear and
false, or accurate and impossible to follow. Label claims needing research or
fact-checking without resolving them unless requested.

## Run the Six Passes

Work in dependency order:

1. Compare the introduction and conclusion points and formulate the best
   supported working point sentence.
2. Determine whether the draft is point-first or intentionally point-last, then
   test whether the opening creates the needed expectation.
3. Map each section to the reader question it answers, its index point, and its
   transition from the preceding section.
4. Map consequential assertions as point → reason → evidence and identify the
   first unsupported link.
5. Test discussion sections for an Uneven U: point, explanation, preparation,
   evidence, interpretation, and broader resolution.
6. Compare the certainty of each important claim with the scope and strength of
   its support.

Fix upstream problems before polishing downstream sentences. A drifting central
point can create apparent transition, evidence, and certainty problems across
the entire draft.

## Classify Findings

Use states instead of a synthetic overall grade:

| State | Meaning |
| --- | --- |
| Clear | A cold reader can follow the intended relationship from the text. |
| Strained | The relationship is recoverable, but wording or placement imposes avoidable work. |
| Broken | A missing, contradictory, or unsupported link prevents reliable understanding. |
| N/O | The draft does not contain enough material to observe the relationship. |

Rank findings by reader cost and architectural reach. Prefer one diagnosis that
explains several symptoms over a list of isolated line edits.

## Deliver the Evaluation

Return:

1. **Cold-reader verdict:** the point a reader can currently recover, where it
   becomes clear, and the principal clarity constraint.
2. **Point alignment:** introduction point, conclusion point, their relationship,
   and a proposed working point sentence when synthesis is needed.
3. **Six-pass diagnostic:** each pass marked Clear, Strained, Broken, or N/O,
   with concise evidence and reader effect.
4. **Logic map:** for each major section, show its reader question, index point,
   strongest point-reason-evidence chain, and transition dependency. Omit empty
   columns rather than inventing material.
5. **Revision order:** no more than three high-leverage changes, ordered by
   dependency and paired with their expected clarity gain.
6. **Verification boundary:** factual, evidentiary, or audience assumptions the
   prose alone cannot establish.

Use short quotations or stable section and line references for material
judgments. Describe strengths where the draft gives the reader a reliable
bridge; do not make the report a defect inventory.

## Revise When Requested

Preserve the author's meaning, voice, citations, and intentional complexity.
Start with the highest-leverage structural repair, then make the smallest
coherent prose changes that test it. Re-read the affected material from a cold
start and report which clarity states changed and which tradeoffs remain.
