# Software Factory: Inputs, Outputs, and Control

Editorial note for *The Knowledge Factory*: explicitly designate these three
pairs when describing or diagramming the software factory.

- **Input / output:** what enters each stage (intent, evidence, requirements,
  constraints) and what leaves it (decisions, specifications, code, verification
  evidence). Distinguish a produced artifact from the outcome it is meant to
  create.
- **Triage / validation:** triage clarifies, prioritizes, and routes incoming
  work; validation checks whether a result satisfies the intended need and
  acceptance criteria. Show where work is accepted, returned, or escalated.
- **Declarative / imperative:** declarative descriptions state what should be
  true, including desired outcomes and constraints; imperative instructions
  specify how to act, including steps, commands, and procedures.

Do not collapse these into one distinction: inputs and outputs can each contain
declarative statements or imperative instructions. Triage and validation can
recur at each stage, not only at the factory's outer boundaries.
