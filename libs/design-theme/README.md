# Design Theme

## Purpose

This library provides the typed THOM visual foundation shared by local content
tools.

## Ontology

The design foundation contains stable color, typography, and effect tokens. It
does not own product layout, tool geometry, React components, or generated
assets; those remain with consumers.

## Key Terms

- **Foundation token:** a reusable visual value with semantic meaning.
- **Consumer theme:** a tool-owned extension of the foundation.
- **Public API:** `ThomToolFoundation` and `thomToolFoundation`.
